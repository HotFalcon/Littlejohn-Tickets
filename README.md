# Littlejohn Tickets

Source for [littlejohntickets.com](https://littlejohntickets.com), served by GitHub Pages from `main`.

Plain static files, no build step: `index.html`, `privacy.html`, `terms.html`, `styles.css`, the icons and
`og.png` (link preview). `CNAME` holds the domain.
Preview locally with `python -m http.server` and open http://localhost:8000.
